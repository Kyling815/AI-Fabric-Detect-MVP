AI Fabric Defect Detection MVP - Work Report
Date: 2026-06-15

Summary
This project is now a working backend MVP for fabric defect inspection. The system can discover configured datasets, validate uploaded images, preprocess them, split them into patches, extract CNN features, project embeddings through a trained projection head, compare patches against normal reference libraries with FAISS, score anomalies, merge suspicious patches into defect boxes, classify the final result, save annotated output images, and store inspection history.

The project has moved from a single DME-only reference into an early multi-fabric reference-library system. The current reliable runtime default is the extended DME reference:

FABRIC_DEFAULT_REFERENCE_ID=dme_plain_extended_v1_100

Preprocessing Behavior
- Uploaded images are converted to RGB.
- The image keeps its aspect ratio.
- If the longest side is greater than 768 pixels, it is resized so the longest side becomes 768 pixels.
- If the image is already 768 pixels or smaller on its longest side, it keeps its original size.
- The resized image is split into 96 x 96 pixel patches.
- Patches are sampled with a stride of 48 pixels.
- Each patch is fed to ResNet18 at 224 x 224 pixels.

Example:
Original image: 1920 x 1080
Preprocessed image: 768 x 432
Patch size: 96 x 96
CNN input per patch: 224 x 224

Computer Vision Pipeline
- Implemented patch extraction with configurable patch size and stride.
- Implemented ResNet18 feature extraction.
- Added CUDA/CPU fallback with FABRIC_DEVICE=auto.
- Added support for pretrained torchvision weights.
- Added optional projection-head embedding support.
- Added FAISS index build, load, and nearest-neighbor search.
- Uses cosine-style nearest-neighbor scoring for patch anomaly detection.
- Merges suspicious patches into defect boxes.
- Filters merged boxes by minimum cluster size.
- Generates annotated images with detected boxes.

Runtime Classification Update
The runtime classifier was adjusted so the area thresholds behave as intended:

- If defect area ratio is below FABRIC_GOOD_AREA_THRESHOLD, classify as Good.
- If defect area ratio is at or above FABRIC_BAD_AREA_THRESHOLD, classify as Bad.
- If defect area ratio is between the two thresholds, classify as Acceptable.

This preserves the intended Acceptable band. The classifier no longer forces Bad purely because many small boxes were detected.

Current classification thresholds:

Good threshold: 0.02
Bad threshold: 0.10

Current interpretation:

defect_area_ratio < 0.02 -> Good
0.02 <= defect_area_ratio < 0.10 -> Acceptable
defect_area_ratio >= 0.10 -> Bad

Known Issues and Important Findings
- Fabric style matters. A reference library built from one fabric style will often treat a visually different fabric style as anomalous.
- Good DME/plain images should use dme_plain_extended_v1_100.
- Good WFDD grid images should use wfdd_grid_cloth_extended_v1_100.
- Good WFDD yellow images should use wfdd_yellow_cloth_extended_v1_100.
- Good WFDD pink flower images are not reliable yet with wfdd_pink_flower_extended_v1_100.
- Grey cloth and pink flower need more work before they should be trusted.
- The registry field active_reference_version may still point at the last built reference, but runtime selection is controlled by FABRIC_DEFAULT_REFERENCE_ID or by the explicit reference_id submitted to /api/inspect.
- If .env changes do not appear to take effect, fully stop and restart the Uvicorn process.

Recommended Next Phase
- Keep DME plain, WFDD grid, and WFDD yellow as the currently trusted references.
- Do not promote WFDD grey, WFDD pink flower, or Lusitano references yet.
- Add a frontend reference selector so the user can choose the correct fabric reference during upload.
- Add warnings in the UI when a selected reference is marked experimental.
- Improve pink flower and grey cloth references with better preprocessing, stronger grouping, or a more specialized model.
- Continue collecting per-fabric false positives and false negatives.
- Consider per-fabric threshold presets and per-fabric visual normalization.
